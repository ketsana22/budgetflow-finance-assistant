# Budgetflow-finance-assistant
Project description
-
BudgetFlow is a personal finance assistant designed to help users understand their spending and manage their monthly budget. It uses Python to calculate expenses, track remaining balances, and provide spending summaries. The project aims to make basic financial management easier through a simple and user-friendly interface.

# main features 
-Calculate total monthly expenses.

-Calculate the remaining balance after expenses.

-Provide spending summaries by category.

-Answer budgeting questions using the user's financial information.

-Provide a simple interface for users to interact with the assistant.

# Technologies 
-Python :  Used for budgeting calculations and application logic

-google colab :used to develop and test the program.

-gemini API:Planned for AI-powered budgeting assistance (gemini API is currently have some errors).

-Gradio: Used to create a simple user interface.

# Sample Input and Output

Sample Input
-
Monthly income: $3,500

Rent: $800

Food: $600

Transport: $350

Entertainment: $400

Sample Output
-

Total monthly expenses : $2,150.00

Remaining balance : $1,350.00

The program calculates the total monthly expenses and subtracts them from the user's income to show the remaining balance.

# Input Validation and Testing

BudgetFlow checks user inputs to make sure income and expenses are valid. Testing helps find errors and make sure the calculations work correctly.
