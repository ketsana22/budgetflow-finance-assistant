# budgetflow-finance-assistant
A personal finance assistant for budgeting and expense tracking
budgetflow is a personal finance assiastant designed to help users understand their spending and manage their monthly budget.
# main features 
Calculate total monthly expenses.
Calculate the remaining balance after expenses.
Provide spending summaries.
Answer budgeting questions using the user's financial information.
Provide a simple interface for users to interact with the assistant.
# technologies 
Python, google colab,gemini API, Gradio 
# status 
the project is currently in the planning and development stage.
